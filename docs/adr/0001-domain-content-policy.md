# Domain rules define the visible catalog

Each domain owns its filter choices and fixed content rules, because apps may expose different catalogs through different hostnames. A locked hidden entity or a required entity is a server-enforced access boundary for public reads, including staff and direct media access; an optional reader filter only changes discovery. Internal entities retain their identity and associations for administration and policy but never appear in public metadata or search, so marking an entity internal alone does not hide its associated content everywhere.

Reader choices remain app-owned and survive domain changes. The current domain decides which choices can apply; changing its controls must not erase preferences saved for other domains.
